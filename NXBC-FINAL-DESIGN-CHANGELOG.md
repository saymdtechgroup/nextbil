# NXBC Final Reference Design Replacement

This replacement applies the supplied NXBC reference visual system to the existing public application.

Visual system:
- Midnight navy / near-black background
- Gold glowing borders and primary CTA
- Cyan/teal utility accents
- Compact data cards and consistent rounded corners
- Unified branded header and bottom navigation
- Public pages share the same visual language
- Existing NXBC coin asset remains the primary brand visual

Public UI cleanup:
- Removed user-facing Add NXBC/Add Tokens affordance
- Removed user-facing Admin button/access from Mine/Profile screen
- Removed unverified CertiK audit claim
- Replaced public admin wording with Treasury Wallet where applicable
- Removed showcase "Hot Multi-Sig" label

Functional/business logic is not intentionally changed by the visual pass.
Smart-contract code is not included in this replacement.
